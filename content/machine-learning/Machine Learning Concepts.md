This note serves as a map for the lower-level concepts used in practical machine learning applications. 

# Purpose

Machine Learning serves the purspose of building predictive models. We trust models when we cannot rely on simple rules, and let the model decide it for us from the available data.

# How it Works

Extracts mathematical rules from data which generalize well to new observations.

# Types of Problem

* **Supervised Machine Learning**: Given data matrix $X$ with $n$ observations, predict target property $y$ of observations.
* **Unsupervised Machine Learning**: Given data matrix $X$ with $n$ observations, extract from $X$ a structure that geenralizes.

# Types of Target Variable

Applies in supervised learning. 

* **Regression**: predicting a continuous numerical quantity.
* **Classification**: predicting a discrete label (class).
