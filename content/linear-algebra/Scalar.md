Scalars are plain numbers.

We denote scalars by ordinary lower-case letters (e.g., $x, y, z$). The set of all continuous real-valued scalars is denoted by the real line $\mathbb{R}$.

To indicate that a scalar $x$ belongs to the set of real numbers, we use the **set membership symbol** $\in$ (read as "is an element of" or "belongs to"):
$$x \in \mathbb{R}$$
More generally, if a scalar belongs to a specific domain or subset $\mathcal{S}$ (such as non-negative reals $\mathbb{R}_{\ge 0}$ or complex numbers $\mathbb{C}$), we write:
$$x \in \mathcal{S}$$
## Discrete & Finite Domains 

When a scalar is restricted to a specific set of distinct values, we define the set using **curly braces** $\{\dots\}$. For example, to denote a binary scalar that can only be $0$ or $1$: $$x \in \{0, 1\}$$
